建议结构，而非老师强制给定的目录：
注意：SRS也需要空值在5页以内
章节	内容	可从哪里整理
1. Introduction	背景、目标、系统范围	Proposal
2. Business Requirements	Business Objectives、Product Vision	Proposal
3. User Requirements	Actors、Use Cases、使用场景	Proposal + 课件
4. Functional Requirements	Memory 构建、检索、状态判断、问答、可视化	ABC 模块
5. Data Requirements	LoCoMo 格式、Memory Schema、证据追溯	A 模块
6. External Interface Requirements	Web 界面、API 输入输出	B/C 模块
7. Quality Attributes	正确性、可追溯性、可用性、可维护性	全组
8. Constraints	数据范围、技术与项目边界	Proposal
9. Requirements Traceability	需求与用例、测试之间的对应关系	全组
