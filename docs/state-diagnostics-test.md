# 状态专项测试：16 道原文核对题

日期：2026-10-31。

## 结论

测试已由 Codex 执行，无需用户手动启动程序或整理结果。
本轮首次在针对性的真实历史问题上观察到补检收益，但整体回答仍不稳定：
Hybrid 证据召回从 65.63% 增至 93.75%，平均使用 6 条候选，达到 Top-10 的召回水平；
答案 F1 却从 0.330 降至 0.294，不能据此宣称回答质量整体提高。

两个明确收益是找回工作室较新的经营困难状态，以及补齐“寻找场地 → 经营困难”的变化证据。
主要失败仍是混杂的就业状态产生误冲突、不同属性或空属性的时间锚点无法补齐，以及变化答案过长。

## 题目来源与边界

- 仍只使用开发和演示中已使用的 conv-30，不使用尚未明确划分的其他对话调试。
- 16 道中有 4 道课程原始 QA，12 道为 Codex 在核对真实原文后补写的问题，均明确记录来源。
- 分类：当前状态 5 道、稳定偏好 2 道、状态变化 4 道、可回答的持续时间 2 道、证据不足 2 道、普通事实回归 1 道。
- 标注为 Codex 核对后的暂定标注，未经教师或用户独立复核，不能描述为官方标注或人类评测。
- 使用截至会话 1、6、12、15、18、19 的完整历史前缀；同一个问题在不同阶段的重复不算独立对话。
- 每个前缀保留所有符合截止条件的原始抽取 Memory，不筛选“方便成功”的候选，也不重写 attribute、value 或时间。
- 同时检查 Memory 自身会话及所有 evidence 会话，防止后续证据进入早期快照。
- 全部题目和参考要求先保存，再运行模型；本轮不修改生产检索、补检、解析或答案生成代码。

## 评测方法

固定 Top-3、Top-10、Top-3 + 同槽位补检；使用相同 rules 解析器，补检上限新增 50 条。
BM25 与 Hybrid 各运行三组，总计 96 次查询解析；没有付费 LLM 调用。

- 证据召回：以题目注明的原始证据轮次为主要诊断依据。
- Memory ID 为规范参考，不一定涵盖全部同义证据，不能将其单独解释为语义正确率。
- F1：只计算 14 道可回答题，使用原有本地英文 token 口径；2 道不可回答题单独统计拒答。
- 额外检查答案关键词、有效 Memory 来源，以及部分明确案例的可接受有效记忆集合。
  这是透明的规则诊断，不是通用语义评分器。
- 未提供完整人工关系标签，不报告状态关系准确率。
- 不把本轮耗时当作性能对比：初始化和缓存会影响三组的时间公平性。

## 总体结果

| 检索器 | 方案 | 原始证据轮次召回率 | 平均候选数 | 可回答题 F1 | 可回答题拒答 / 14 |
|---|---|---:|---:|---:|---:|
| BM25 | Top-3 | 59.38% | 3.00 | 0.310 | 5 |
| BM25 | Top-10 | 87.50% | 10.00 | 0.333 | 3 |
| BM25 | Top-3 + 补检 | 84.38% | 6.38 | 0.312 | 4 |
| Hybrid | Top-3 | 65.63% | 3.00 | 0.330 | 4 |
| Hybrid | Top-10 | 93.75% | 10.00 | 0.321 | 4 |
| Hybrid | Top-3 + 补检 | 93.75% | 6.00 | 0.294 | 5 |

补检可以用少于 Top-10 的平均候选量达到相近召回，但这不是严格等预算或速度实验。
本轮题量小、问题之间相关，不能推出泛化效果或统计显著性。

规则诊断通过数两种检索器均从 8/16 到 11/16；其中一项来自“未说明临时雇主名称”的拒答，
系统实际上因就业链冲突而拒答，而非正确识别缺失雇主字段。因此这个通过数包含偶然行为，不能直接作为准确率或全部有效收益。

six months 使用课程原始答案口径，不将“包含起止月份”的规则扩展为通用持续时间定义。

## 测试给出的下一轮代码目标

1. **就业状态的可比较性与历史事实识别。** 同一 employment_status 混入失业回顾、创业意向和当前工作；应区分事实时间与提及时间，并避免不兼容的维度被硬比较。部分抽取还将“失业后过得艰难”强化成“此后一直失业”，需要检查抽取质量。
2. **时间锚点补检与解析。** 开业/录取事件可能没有 attribute，需要针对起止角色的受控检索；相对时间与会话日期需要一致解析，天数与月份不能共用当前按月份生成答案的规则。
3. **变化答案压缩。** 保留完整证据链供展示，答案只概括问题所需的起止状态，避免把整个历史列表直接拼接为最终答案。
4. **字段级证据充分性。** 问“雇主叫什么”不能用“做临时工作”的相关事实代替答案，更不能依赖其他误冲突碰巧拒答。

优先解决前两项，再复测这组开发题；完成后仍需要冻结规则并使用独立测试集。
目前没有找到适合当作清晰“真实未消解冲突”金标的原始案例，本组不捏造此类题。
已有受控冲突回归仍保留，不能冒充真实课程问答的准确率。
