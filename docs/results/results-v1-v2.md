| 模型 | DeepSeek Flash、GLM-4-Flash（GLM-4.7 因限流无有效成绩） | DeepSeek Flash |

## 结论

1. **最大的单一改进是答案提示词**：同题配对下，所有 DeepSeek 方法的 F1 都提升约 6–8 个百分点（表 2，置信区间均不含 0）。因此 v1 → v2 的总提升不能归功于补选。
2. **补选在同一版本内确实有效**：相对 K5，补检 +2.1、Forced Graph +3.1、Adaptive Graph +2.6 个百分点，置信区间均不含 0（表 3）；开发集 650 题上 Adaptive 仍为 +1.5 个百分点、19 升 0 降（表 4），说明收益不是只在测试集上成立。
3. **Adaptive 与 Forced 精度相当，但更稳、更省**：两者 F1 差在测试集与开发集的置信区间都跨 0；Adaptive 在两个集合上都没有下降题，输入 Token 少约 25%。
4. **补选没有超过直接取 K10**：K10 的 F1 比 Adaptive 高 1.8 个百分点（置信区间刚好跨 0），但输入 Token 多约 30%。补选的价值是用更少上下文拿回 K5 → K10 一半以上的收益（约 56%–60%），而不是精度上限更高。
5. **Full Text 仍是精度上限**：F1 0.5692，比 K10 高 6.8 个百分点，但每题约 2 万输入 Token，是 Adaptive 的约 21 倍。
6. **复现性**：同学 11 月 8 日的运行（Fixed / Forced / Adaptive F1 0.4546 / 0.4784 / 0.4859）与本次重测（0.4573 / 0.4887 / 0.4837）各组相差不超过 0.011，Forced 与 Adaptive 的先后在波动范围内互换；同一配置两次请求（Hybrid K5 与 Fixed K5）相差 0.004。
7. **多模型**：GLM-4-Flash 只有 v1 数据；其 Full Text 协议错误过多，Embedding / Hybrid / 补检三组彼此接近（约 0.365），K10 反而更低，且 19–48 次接口错误计 0 分，模型间结论以 DeepSeek 为主。
